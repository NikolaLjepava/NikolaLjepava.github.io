### Ethereum Transaction Crawler

**A web application for exploring Ethereum wallet transactions and historical blockchain data**

**Tech Stack:**

- **Runtime:** Node.js
- **Language:** TypeScript
- **Blockchain Integration:** Alchemy API
- **API:** REST
- **Containerization:** Docker

**Features:**

- Retrieve ETH and token transactions for any Ethereum wallet address
- Support for ETH, ERC20, ERC721, and ERC1155 tokens
- Paginated transaction results
- Historical ETH balance lookup by date
- Web interface for exploring wallet activity
- REST API for programmatic access

**Description:**
A web application that retrieves and displays Ethereum transaction data for any wallet address, starting from a specified block number. Integrates with the Alchemy API to fetch blockchain data and provides both a web interface and REST API for accessing transaction history.

**Status:** Completed - [View on GitHub](https://github.com/NikolaLjepava/Ethereum-transactions-crawler)

### AI Code Reviewer & Regression Detection Agent (Work in Progress)

**An AI-powered code analysis agent for detecting bugs and potential regressions across entire codebases**

**Tech Stack:**

- **Runtime:** Node.js
- **Language:** TypeScript
- **AI:** Local LLM (Ollama)
- **Version Control:** Git
- **CI/CD:** GitHub Actions
- **Code Analysis:** TypeScript Compiler API
- **Containerization:** Docker

**Planned Features:**

- Automated code review triggered by GitHub commits and pull requests
- Repository-wide code analysis
- Detection of potential bugs and regressions
- Dependency and function call analysiss
- Git history analysis to understand previous code changes
- AI-powered investigation and root cause analysis
- Suggested code fixes and regression tests
- Automated review reports with affected components and recommendations

**Description:**
An AI-powered development tool designed to analyse code changes in the context of an entire repository rather than reviewing modified files in isolation. The agent combines static code analysis, dependency tracking, Git history and automated testing to identify potential bugs and regressions that could affect previously implemented functionality.

**Status:** Work in Progress
